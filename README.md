# 🌟 What is Deep Learning?

Deep Learning is a specialized branch of Machine Learning that enables computers to learn complex patterns from large amounts of data using **Artificial Neural Networks (ANNs)**. Unlike traditional machine learning algorithms that rely heavily on manual feature engineering, deep learning models automatically learn meaningful representations directly from raw data.

Deep learning has revolutionized fields such as:

* Computer Vision
* Natural Language Processing (NLP)
* Speech Recognition
* Medical Image Analysis
* Recommendation Systems
* Autonomous Vehicles
* Robotics
* Financial Forecasting
* Time Series Prediction
* Generative AI

Today, technologies like ChatGPT, image generators, voice assistants, and self-driving cars are all powered by deep learning.

## 🔹 Recurrent Neural Networks (RNN)

Unlike traditional neural networks, Recurrent Neural Networks can remember previous information using hidden states. They are useful for sequential data where order matters.

Topics included:

* Sequential Data
* Hidden State
* Time Steps
* Sequence Prediction
* Many-to-One Architecture
* One-to-Many Architecture
* Many-to-Many Architecture
* Vanishing Gradient Problem
* Exploding Gradient Problem
* Backpropagation Through Time (BPTT)

Applications:

* Text Classification
* Sentiment Analysis
* Spam Detection
* Language Modeling
* Time Series Forecasting
* Weather Prediction
* Music Generation

## 🔹 Long Short-Term Memory (LSTM)

LSTM is an advanced version of RNN that solves the vanishing gradient problem by introducing memory cells and gates.

Topics included:

* Memory Cell
* Cell State
* Hidden State
* Forget Gate
* Input Gate
* Output Gate
* Candidate State
* Long-Term Memory
* Sequence Learning
* Bidirectional LSTM
* Stacked LSTM

Projects:

* Stock Price Prediction
* Next Word Prediction
* Sentiment Analysis
* Electricity Consumption Forecasting
* Weather Forecasting
* Language Translation
* Text Generation

## 🔹 Gated Recurrent Unit (GRU)

GRU is a simplified version of LSTM with fewer parameters and faster training while maintaining strong performance.

Topics included:

* Time Series Prediction
* Text Classification

Comparison Covered:
